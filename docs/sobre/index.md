# Sobre o projeto

Projeto final da disciplina **FGA0315 Qualidade de Software 1** (UnB/FCTE, 2º semestre de 2026, Turma 01), ministrada pela Profa. Cristiane Soares Ramos. O objetivo é avaliar a qualidade de um produto de software seguindo o processo de avaliação da série SQuaRE.

O grupo leva o nome de **Marlyn Wescoff** (1922–2008), uma das seis programadoras originais do ENIAC, o primeiro computador eletrônico de propósito geral. A identidade visual do site usa as cores dos painéis de lâmpadas do ENIAC como referência.
