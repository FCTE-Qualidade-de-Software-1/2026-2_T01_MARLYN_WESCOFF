# Fase 1: Estabelecer os requisitos da avaliação

A Fase 1 responde às perguntas que precisam estar resolvidas **antes** de escolher métricas ou coletar dados: por que avaliar, para quem, qual produto, com qual modelo de qualidade e até onde. O resultado desta fase orienta diretamente a [Fase 2](../fase-2/index.md).

## Síntese

| Item | Decisão |
|---|---|
| Produto | Moodle 5.3 LTS, núcleo com tema Boost e sem plugins de terceiros, em instalação local controlada |
| Tipo de produto | Aplicação web cliente-servidor, LMS de código aberto (GPLv3); COTS na classificação IEEE 1062 |
| Propósito | Apoiar a decisão de adoção ou atualização para o Moodle 5.3 LTS em uma instituição de ensino superior |
| Requisitante no cenário | Coordenação de TI da instituição (cenário); requisitante acadêmico: docente da disciplina |
| Modelo de qualidade | ISO/IEC 25010:2023, adaptado ao contexto |
| Características priorizadas | 1º Adequação funcional · 2º Compatibilidade · 3º Flexibilidade |
| Profundidade | Avaliação externa, predominantemente caixa-preta, orientada a tarefas |
| ODS | ODS 4 (metas 4.3, 4.4 e 4.a) |
